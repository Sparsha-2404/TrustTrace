## Important limitations

This environment did not have ChromaDB installed, did not connect to the user's
LM Studio server, and did not load the real SentenceTransformer model. Therefore
this test report does not certify live retrieval, end-to-end enforcement,
persistent recovery, or Windows compatibility. The user's previous local
results (104 tests, live LM Studio completion, semantic embeddings, and
cross-process ChromaDB persistence) were obtained on the pre-follow-up source
revision and must be repeated after installing this package.

The experiment's attack-success metric is still a final-generator lexical
marker proxy, not a scenario-specific semantic goal oracle. A deterministic
false-positive case was found in the previous report: the system's own
`[BLOCKED] ... compromised pipeline` refusal contained a generic marker. The
proxy now excludes system-generated `[BLOCKED]` and `[QUARANTINED]` outputs. The package is not
ready for final conference claims.
